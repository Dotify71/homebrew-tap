# Dotify71 Tap

## How do I install these formulae?

`brew install dotify71/tap/<formula>`

Or `brew tap dotify71/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dotify71/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
